QTLMapper3

QTL mapping, GWAS, genomic prediction, population genetics, selection scans, meta-QTL analysis and variant annotation in one fast, validated package, with a desktop app and a scriptable command line.

DownloadGUI tutorialCLI tutorial

What it does

Exact genotype probabilities

HMM for BC, F2, RIL (selfing/sib) and DH with error model, dominant markers, four map functions and pseudomarker grids.

Every major QTL scan

Haley–Knott, EM, LMM with LOCO kinship, binary traits, CIM, ICIM, two-QTL scans, stepwise multiple-QTL models.

Permutations in seconds

Permutations run as extra phenotype columns through one shared factorisation: 1,000 permutations take about half a second.

GWAS

GLM, MLM (P3D/EMMAX) with LOCO kinship and PCs, and MLMM with mBonf/EBIC model selection.

Genomic prediction

GBLUP, RR-BLUP, A/D/epistatic/RKHS kernels, multi-environment G×E, BayesA/B/C, BRR, Bayesian LASSO, ML models, CV0/CV1/CV2/CV00.

Population genetics

PCA, trees, ADMIXTURE-model ancestry with CV, FST, π, Tajima's D, LD decay and blocks, maps of ancestry pies.

Selection scans

iHS, nSL, XP-EHH, H12, PBS and PCAdapt for positive selection; πN/πS, SFS and load for purifying selection; Tajima's D and Fay & Wu's H.

Meta-QTL

Map projection, consensus maps and meta-analysis across studies with five model-selection criteria and heterogeneity statistics.

Variant annotation

snpEff from the command line: effect tables, impact summaries and annotated GWAS/QTL hits with nearest genes.

Validated

Results checked against R/qtl, R/qtl2, rrBLUP, sommer, BGLR and scikit-allel; the checks run in the test suite.

Install

Download the build for your system from Releases (macOS .zip, Windows .zip, Linux .tar.gz). The app tells you when a new version is out.

git clone https://github.com/ank-man/qtlmapper3.git
cd qtlmapper3
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py                 # desktop app
python qtlmapper3_cli.py --help  # command line

GUI tutorial

1

Launch and load data

Start with qtlmapper3-gui (or python main.py). Use File → Import Data for your genotype, phenotype and map files, or File → Load Demo Data for a 200-individual F2 cross with three traits.

2

Inspect your data

Double-click Genotypes, Phenotypes or Genetic map in the sidebar to open a sortable table. Double-click any entry under Figures to open it in the Visualization Studio.

3

Map QTL

Analysis → QTL Mapping. Choose the trait and method: hk, em, lmm (kinship with LOCO), cim, icim, binary or sm. Set the permutations (1,000 is a good default) and an output folder. A results tab opens with the LOD profile and effect plots. Peaks, support intervals and the genome-wide threshold go to the log and the sidebar.

4

Explore results in the Visualization Studio

Visualization → Create Figures, or double-click a result in the sidebar. Pick a figure on the left, adjust trait, chromosome or peak, zoom and pan with the toolbar, and Export figure… to PNG, PDF, SVG or TIFF at any DPI.

5

Genomic prediction and GWAS

Analysis → Genomic Selection compares models by 5-fold cross-validation (GBLUP, RR-BLUP, dominance/epistasis kernels, RKHS, BayesA/B/C, BRR, Bayesian LASSO, random forest, gradient boosting, SVR). Analysis → GWAS runs GLM, MLM with LOCO kinship, or MLMM.

6

Stay up to date

QTLMapper3 checks GitHub for a new release when it starts (at most once a day) and offers to download it. You can also use Help → Check for Updates…, or turn the startup check off in the popup.

Command-line tutorial

Every example below is a real run on the bundled demo data (data/demo_f2: 200 F2 individuals, 100 markers, three simulated QTL for yield on chromosomes 1, 3 and 4; data/demo_gwas: diversity panel).

Single-QTL genome scans

One command reads the data, computes HMM genotype probabilities on a 1-cM grid, scans, runs permutations, finds peaks with 1.5-LOD and Bayes support intervals, and writes tables and figures.

Selection scans

Positive selection (iHS, nSL, XP-EHH, Garud H12/G12, PBS, PCAdapt-style outliers), purifying selection (πN/πS, site-frequency spectra by functional class, genetic load) and balancing selection or neutrality (Tajima's D, θπ, θW, Fay & Wu's H) in one run. Windows that are outliers for at least two statistics are reported as candidate regions. The haplotype statistics match scikit-allel to machine precision. Demo: data/demo_selection (simulated: a partial sweep in North on chr1, balancing selection on chr2, purifying selection on missense and loss-of-function sites).

$ qtlmapper3 selection --vcf data/demo_selection/selection.vcf.gz -p data/demo_selection/populations.csv --focal North --contrast South \

Meta-QTL analysis

BioMercator/MetaQTL workflow: QTL from different studies are projected onto a consensus map (piecewise homothetic through common markers, order conflicts removed), clustered by a Gaussian mixture with known variances, and the number of meta-QTL chosen by AIC, AICc, AIC3, BIC or AWE. Each meta-QTL comes with Cochran's Q and I², outlier flags and an optional leave-one-study-out check. Demo: data/demo_metaqtl (six simulated studies, eight true meta-QTL).

$ qtlmapper3 metaqtl --qtl data/demo_metaqtl/qtl.csv --maps data/demo_metaqtl/maps --consensus data/demo_metaqtl/consensus_map.csv --loso \

Variant annotation with snpEff

QTLMapper3 runs an installed snpEff (Cingolani et al. 2012; not bundled) and turns its ANN field into tables, a summary figure and annotated GWAS/QTL hit lists with nearest genes.

qtlmapper3 annotate databases --search oryza
qtlmapper3 annotate run --vcf calls.vcf.gz --genome Oryza_sativa --download -o results/annotate
qtlmapper3 annotate hits --hits results/gwas/gwas_yield_significant.csv \
    --vcf results/annotate/annotated.vcf --gff genes.gff3 --flank 50000 -o results/annotate
$ qtlmapper3 annotate parse --vcf example.ann.vcf \
